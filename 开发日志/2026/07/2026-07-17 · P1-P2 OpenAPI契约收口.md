# 开发日志：P1/P2 OpenAPI 契约收口

日期：2026-07-17  
分支：`codex/openapi-p1-p2-contracts`

## 目标

关闭 `D-OA-P12`：将已实现的 P1/P2 服务端路由补入 `specs/api/openapi.yaml`，补齐请求体、响应体、错误模型、Bearer 认证与 owner/成员权限说明，并重新生成 Dart client。P1/P2 业务 repository 本轮继续保留手写实现，不做无关重构。

## 已写入

- P1 41 个操作：成员、CRM、合同/回执、记账、遗传、推送、权益。
- P2 24 个操作：官网、小程序、只读助手、跨舍借配。
- 92 个命名 schema，覆盖请求、资源、列表/单体 envelope、错误引用和状态枚举。
- 公开主页 slug 读取明确为匿名 `security: []`；其余 P1/P2 操作使用 Bearer owner scope。
- 生成后 Dart enum 默认值校正：`lead`、`unknown`、`pro`，保持 `build_runner` 后可编译。
- `generated/dart/scolvpet_api` 新增 P1/P2 API 分组、模型、文档与序列化文件。

## 计数口径

- 既有 OpenAPI：86 个唯一 URL 模板 / 108 个操作。
- 本轮新增：47 个唯一 URL 模板 / 65 个操作（P1 28 模板、P2 19 模板）。
- 当前合计：133 个唯一 URL 模板 / 173 个操作。

“65 条路由”按服务端 `HandleFunc` 的 method+path 操作计数；同一 URL 的多个 HTTP 方法在 OpenAPI 中共享一个 path object，不虚增唯一模板数。

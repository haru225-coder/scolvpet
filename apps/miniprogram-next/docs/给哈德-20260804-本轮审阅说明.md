## 建议你重点抽查

1. **试配**：种群/我的 → 试配模拟 → 选系列/公/母 → 出「模拟结果」；目录失败仍能选样子。
2. **个体详情**：先进身份卡概览，不该一屏全是表单；编辑/体重/健康分段可用。
3. **错误文案**：断网/401 应是中文产品句，不要 raw English 堆栈味。
4. **旧深链**：打开 `packages/breeding/*` 应 redirect 到试配，不 404。
5. **权限**：viewer 在个体详情看不到头像上传/保存等写入口。

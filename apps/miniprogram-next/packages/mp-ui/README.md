# @scolvpet/mp-ui

小程序 UI 组件库。深色经营端默认。

## 反 AI 味约定（2026-08-02）

1. **空白合法**。NavBar 右槽没有真信息就别挂东西；禁止用标题复读徽章填空。
2. **橙色只给真选中**。底栏 active、筛选下划线可以橙；装饰性 Tag/头像/大色块不要橙。
3. **语义色才有色**。健康 / 隔离 / 待检 / 危险动作走 success / warning / danger；别用品牌橙冒充状态。
4. **禁止假图**。无照片用中性底 + 首字，不要渐变色带冒充宠物海报。
5. **禁止黑底大投影**。分层靠 1px 描边和背景阶，不靠 `0 10px 28px` 糊脏边。
6. **字重封顶 600**。不要 800/900；标题靠字号与留白，不靠加粗压人。
7. **字阶只留 body 三档**（`bodyLarge/Medium/Small`）。禁止恢复 `display*` / `headline*` 重档。
8. **装饰不能治 AI 味**。不要加回 `wobble` / 纸纹 / 蜡笔下划线 / 默认贴纸。
9. **业务页默认不开 Skyline**。Tab 页开 Skyline 会导致 custom-tab-bar 飞顶；2026-08-03 起分包页也统一 WebView，避免渲染器混用。底栏自绘 `position: fixed`。

改视觉前先问：这里是信息还是装饰？是装饰就删。

## 兼容壳（勿再扩大）

下列 prop **视觉已废弃**，仅保留以免旧调用方类型报错；新代码不要传：

| prop | 组件 | 说明 |
|------|------|------|
| `tone` | `Hero` | 不再换配色 |
| `featured` / `seed` | `PosterCard` | 不再放大、不再假色轮换 |
| `tilt` | `Sticker` | 线稿不再歪放 |

下版本可删；调用方应先清零再删类型。

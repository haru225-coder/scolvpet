## 2. “全量收口”的完成定义

一个功能只有同时满足以下条件，才允许标记为“已收口”：

1. **入口真实**：主导航、“我的”或业务详情中的入口与实际能力一致。
2. **数据真实**：生产路径读取真实 API/数据库，不使用生产树内 Memory/Fake 或静态假数据。
3. **契约唯一**：新接口先写 OpenAPI，再生成客户端；移动端不新增平行 path/JSON 契约。
4. **权限完整**：服务端强制 owner/organization/role 边界，客户端只做体验层显隐。
5. **状态完整**：加载、空数据、离线、失败、无权限、冲突、提交中、成功均有明确反馈。
6. **链路可达**：创建后可在列表或详情看到；状态变化后相关首页、日历或统计同步更新。
7. **失败可恢复**：超时、重复提交、部分失败和后台任务失败有重试或明确处理方式。
8. **自动化通过**：定向测试与全量门禁通过，无靠跳过测试掩盖的主路径。
9. **真环境验收**：涉及数据库、对象存储、短信、AI、分享或签名的能力完成真实环境 smoke。
10. **证据留存**：测试结果、真机截图、生产探针、迁移与回滚信息进入开发/运维日志。

未达到上述条件的能力只能处于以下两种状态之一：

- **待确认**：保留只读说明或明确“准备中”，且不产生虚假业务结果。
- **隐藏**：从正式用户主流程移除入口，保留代码与后续立项资料。

## 5. P0 用户验收脚本

### UAT-01 登录与会话

请求验证码 → 登录 → 建舍/进入已有组织 → 杀进程 → 重开恢复 → access token 过期后刷新 → 退出。

### UAT-02 成员协作

舍主邀请照护员 → 受邀账号登录进入同一熊舍 → 可完成任务但不可改套餐/成员 → 舍主修改角色 → 权限即时生效 → 撤销后拒绝访问。

### UAT-03 仓鼠与笼舍

新增仓鼠 → 上传头像 → 入笼 → 记录体重与健康 → 转笼 → 查看完整详情 → 归档；所有关联页同步。

### UAT-04 繁育与窝次

选择父母 → 近亲检查 → 发布计划 → 开始配对 → 分离 → 确认孕期 → 记录出生 → 调整数量 → 断奶/分性 → 个体化 → 关闭窝次。

### UAT-05 今日照护

创建任务 → 工作台出现 → 日历可见 → 完成任务 → 首页、任务列表、组件同步消失或变为已完成。

### UAT-06 客户交付

新建客户 → 选择公开可预订仓鼠 → 确认预订 → 安排交付 → 完成交接 → 状态与客户关系更新。

### UAT-07 合同与回执

从交付生成合同/回执 → 预览 → 签发 → PDF → 系统分享 → 公开打开 → 撤销 → 链接失效。

### UAT-08 数据中心

导入 CSV → 预检错误修正 → 提交 → 导出 → 创建备份 → 校验完成 → 失败任务重试。

### UAT-09 Assistant

连续闲聊 → 查询本舍在养数 → 查询逾期任务 → 创建称重任务确认卡 → 确认执行 → 任务列表可见 → 模型上游中断后规则降级。

### UAT-10 公开获客

发布公开主页 → 客户打开 → 查看可公开仓鼠 → 提交预订/咨询 → App 内出现线索 → 完成后公开状态同步。

## 7. API、数据与架构约束

1. 新 endpoint 必须 `OpenAPI → regenerate → mobile generated client`。
2. 不为生成模型再建无语义 DTO 镜像；只允许有业务语义的 UI state/聚合。
3. 新 API 默认 `handler → store/SQL`；仅跨资源事务、复杂不变量、幂等编排或多入口复用时增加 service。
4. Assistant tool 必须复用已有业务入口或等价不变量，不在 `aicore` 复制整套 SQL。
5. 所有业务写入都要 owner/organization 隔离、权限、幂等和审计。
6. 生产树不新增测试 Memory/Fake。
7. App 根依赖通过 `AppServices` 收束，不继续拉长 `ScolvPetApp` 参数。

## 9. 发布阻断项

出现以下任一情况，版本保持“待确认”，不得标记已封板：

- P0 主路径出现数据丢失、跨 owner 读取、越权写入或不可逆错误迁移。
- 数据库迁移与 API 二进制契约不一致。
- 新 OpenAPI endpoint 尚未生成客户端，移动端仍走新增 direct Dio。
- Flutter / Go / Web / migration / OpenAPI / client drift 任一门禁失败。
- 正式包签名、entitlements、Bundle ID 或 API base URL 错误。
- 生产对象存储、短信、AI 等被正式入口依赖，但真实 smoke 未通过。
- 主导航存在死入口、假成功或沙箱数据冒充生产结果。
- 无可执行回滚方案或未记录生产变更哈希。

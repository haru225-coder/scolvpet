## 3. M0 任务展开(本窗口范围,预计 1–2 窗口)

### M0-1 Taro 工程基座
- `apps/miniprogram-next`:Taro 4.x + React + TS,编译目标 weapp;ESLint/格式与仓库 `docs/engineering/` 约定对齐。
- **分包地图**先行:主包 = 登录 + 今日 Tab + mp-ui;B 端各域(个体/繁育/CRM/合同/财务/AI)预留分包位。CI 加体积门禁(单分包 <2MB,预警线 1.6MB)。
- 移植 fail-closed 构建:对齐 `scripts/build-miniprogram.sh` 的全部校验规则(AppID 格式/https/禁 staging `p.scolv.com`/禁端口/防注入),新增 `make release-miniprogram-next` 与坏值 fixture 测试;开发默认仍 `touristappid` + staging。
- Skyline:按页面粒度声明 `renderer: skyline`,自定义导航栏 + 手势返回;低端机不达标页面允许回退 WebView 渲染(docs/32 §9)。

### M0-2 设计规范与 token
- 从 `ios_theme.dart` 导出 TS token 文件(色彩/字号/间距/圆角/动效强度),产出《小程序仿 iOS 设计规范》一份(docs/34 预留号)。
- 原型缺口:`prototype/figma-import` 只画了 Flutter 五导航,小程序画板缺——M0 以设计规范文字稿 + 样例页代替,Figma 补板不阻塞。

### M0-3 组件库 `@scolvpet/mp-ui`(工程内 package)
最小集(样例页要用到的优先):iOS 风格 NavBar(大标题滚动收缩)、SectionList、Cell/Form 行、SwipeAction、Sheet/ActionPanel、SegmentedControl、按钮/标签/空态。快照测试(vitest)。

### M0-4 TS 契约客户端
- `openapitools.json` 增 typescript 生成器 → `generated/ts/scolvpet-api`;Taro adapter 注入 `Taro.request` + token + `Idempotency-Key`。
- CI 增 ts client-drift 检查(对齐 Dart 客户端既有机制)。**禁止手写 fetch 封装**。

### M0-5 C 端 7 页混入回归
现有 `apps/miniprogram` 7 页(index/catalog/detail/pedigree/simulate/my-reservations/contract)以原生页面形式并入 Taro 工程;15 个既有单测(`test/*.test.mjs`)迁移后必须全过;旧目录在真机回归 PASS 前**不删**。

### M0-6 样例页 + 真机手感 Gate(M0 出口)
- 用 mp-ui 搭 1–2 个样例页(建议:今日照护队列静态样例 + 个体列表样例,只读假数据即可)。
- **Gate 判据**:客户双机 + 开发机真机体验,滚动/转场/手势返回手感与 Flutter 端对照可接受;CI 全绿(taro build + vitest + 迁移后的 15 个 C 端测试 + 体积门禁)。

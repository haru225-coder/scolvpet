# 熊舍管家 MVP 规格交付 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

**Goal:** 产出可直接进入研发评审的 PRD、Figma 低保真、PostgreSQL Schema、OpenAPI 3.1 草案和 16 周开发排期。

**Architecture:** Flutter 客户端连接模块化单体 REST API；PostgreSQL 保存租户业务事实、领域事件、异步任务与用量计量，对象存储承载媒体和备份。繁育与数量闭环使用动作式接口、幂等键和乐观锁。

**Tech Stack:** Flutter、REST、OpenAPI 3.1、PostgreSQL 17、S3 兼容对象存储、Figma Design。

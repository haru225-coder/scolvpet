# 本地开发

## PostgreSQL

无 Docker 时可使用本机 PostgreSQL 15。复制 `.env.example` 为 `.env` 后，根目录 Makefile 会读取其中的本地配置和构建超时变量：

```bash
initdb -D /tmp/scolvpet-pg15/data --no-locale --encoding=UTF8
pg_ctl -D /tmp/scolvpet-pg15/data -o "-p 55432 -k /tmp/scolvpet-pg15" start
createdb -h 127.0.0.1 -p 55432 scolvpet
DATABASE_URL='postgres://localhost:55432/scolvpet?sslmode=disable' db/scripts/migrate.sh --seed
```

停止：

```bash
pg_ctl -D /tmp/scolvpet-pg15/data stop
```

## 主命令

- `make db-verify`：全新临时库执行全部迁移、种子和 38 表/60 枚举计数。
- `make migration-drift`：显式从冻结 Schema 生成临时拆分结果并检查已写入迁移漂移；运行迁移本身不重写历史文件。
- `make api-test`：Go 单元测试。
- `make generate-client`：固定 OpenAPI Generator 生成 `generated/dart/scolvpet_api/`。
- `make outbox-test`：验证 PostgreSQL claim 并发、失败退避、dead-letter、stale lease 回收。
- `make timeout-test`：验证构建命令超时包装器的正常退出和退出码 124 超时路径。
- `DART_PUB_OFFLINE=1 make client-drift`：在本机 Dart 缓存完整时离线验证生成客户端漂移；OpenAPI Generator、Dart 依赖解析和 `build_runner` 默认各有 300 秒超时。
- `make ci`：迁移复跑/checksum、OpenAPI、API、Outbox、Web、Flutter analyze/test/Android debug build 和生成漂移检查。Flutter/Gradle 命令有超时保护，可用 `FLUTTER_COMMAND_TIMEOUT_SECONDS`、`FLUTTER_BUILD_TIMEOUT_SECONDS`、`GRADLE_NETWORK_TIMEOUT_MS` 调整。GitHub Actions 将 lint、test、build 分离，并单独检查 iOS 26.5 simulator runtime。
- `make smoke`：启动 API 后跑 I1 API 演示链。

## Flutter

工程基线为 Flutter `3.44.0` stable（bundled Dart `3.12.0`），Go 为 1.26，Node.js 为 22，PostgreSQL 为 15。Android 固定 compile/target SDK 36、最低 API 21、NDK `28.2.13676358`；iOS 最低版本为 13.0，simulator 构建要求 iOS 26.5 runtime。推荐使用 `make flutter-pub-get`、`make flutter-analyze`、`make flutter-test`；安装 Android SDK 和 JDK 17 后使用 `make flutter-build-android`。debug APK 位于 `apps/mobile/build/app/outputs/flutter-apk/app-debug.apk`。当前开发标识为 `cn.scolvpet.dev`，正式值只在 `apps/mobile/android/mobile-identifiers.properties` 替换；正式 Bundle ID/applicationId、签名团队和发布配置待确认。

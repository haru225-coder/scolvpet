## 构建入口与产物

CI 将检查拆成以下 job：

- `lint`：OpenAPI、迁移、生成客户端、Web 和 Flutter analyze。
- `test`：Go/API、集成 smoke、Outbox、Web 和 Flutter tests，使用 PostgreSQL 15.17 service。
- `build-android`：Flutter debug APK，上传 `apps/mobile/build/app/outputs/flutter-apk/app-debug.apk`。
- `build-web`：Web build。
- `build-ios-simulator`：要求 iOS 26.5 simulator runtime，缺失时先输出 Xcode、runtime 和可用设备诊断。

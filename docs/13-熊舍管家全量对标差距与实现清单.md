## 4. 值得从宠舍复用的「交互与机制」（非代码）

1. **快捷记录入口**（宠物/繁育/待办/日常）→ 熊舍首页+浮动操作。  
2. **繁育四段心智** → 映射为更细状态，但保留「计划→执行→带崽→归档」叙事。  
3. **双通道幼崽体重预警**（服务号+App）文案结构 → 本地通知+任务。  
4. **报喜卡/产仔成功反馈** → confirm-birth 后分享卡片（媒体+share 已有）。  
5. **WebView 会员/编辑器边界** → 远期公开页；Bridge 鉴权模式（token 注入）可参考。  
6. **entitlements+用量** 商业化包装 → 已有 usage 表，上线付费时接。  
7. **GetX 分层** 不必照搬；熊舍可用现有 feature controller + 生成客户端。

## 5. 仓鼠必须重构的差异清单（不可猫化）

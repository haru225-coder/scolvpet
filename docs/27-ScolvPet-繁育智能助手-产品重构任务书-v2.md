# ScolvPet 产品重构任务书 v2.0

日期：2026-07-25  
主题：从「宠舍管理 SaaS」切换为「金丝熊繁育智能助手」  
性质：**信息架构与第一感知重构**，不是推倒重做；保留底层遗传 / 谱系 / 档案能力。

---

## 总目标

用户打开 ScolvPet 后，第一分钟必须感受到：

> “这个东西能帮我预测繁育结果、管理血统、展示我的专业能力。”

而不是：

> “我要学习一个仓库管理软件。”

一句话：

> **把 ScolvPet 从“帮繁育者记账管理”改成“帮繁育者做繁育决策”。**

---

## 一、定位

### 原定位（废弃）

```
宠舍管理系统 → 工作台 → 仓鼠管理 → 繁育管理 → 客户管理
```

问题：ERP 感强、用户无主动管理动力、价值出现太晚。

### 新定位

```
ScolvPet
我的繁育空间
  ↓
🧬 血统谱系
🔮 繁育模拟
🐹 个体档案
📋 宝宝/客户
```

---

## 二、App 首页（P0）

标题：**我的繁育空间**

| 优先级 | 模块 | 说明 |
|--------|------|------|
| 1 | 🔮 繁育模拟 | 选父本+母本 → 开始模拟 |
| 2 | 🧬 我的血统库 | 最近查看 / 有父母信息的个体 |
| 3 | 🐹 我的仓鼠 | 进入个体档案列表 |
| 4 | 📋 客户预约 | 降低权重，不放第一层心智 |

暂停作为首页主内容：今日待办、经营概览、繁育动态（能力保留、入口降级）。

---

## 三、繁育模拟（P0 核心）

- 选公 + 母 → 展示模拟结果
- 基础结果：毛色 / 品种 / 携带 概率
- 遗传说明：「为什么？」消费权威计算结果，**禁止修改**品种规则、毛色规则、基因推算逻辑

---

## 四、血统谱系（P0）

- 文案：不要「谱系管理」，改 **血统档案**
- 树状：祖代 / 父本母本 / 当前个体 / 后代
- 点击跳转个体档案

---

## 五、个体档案（P1）

顺序：身份 → 🧬 血统 → 🔮 繁育价值 → 基础资料 → 健康 → 成长

---

## 六、底栏（P0）

| 旧 | 新 |
|----|----|
| 工作台 | 首页 |
| 仓鼠 | 模拟 |
| 繁育 | 仓鼠 |

模拟进一级 Tab；繁育进度 / 窝次等流程入口降级为二级 push。

---

## 七、冻结（非当前卖点）

CRM 深化、财务、复杂经营报表、任务系统主推、大量待办、数据统计 Dashboard。

---

## 八、小程序

客户侧不变（看宝宝 / 预约 / 沟通 / 确认购买）。  
依赖 App 生成：宝宝展示页、血统介绍页、模拟结果展示页（Sprint 3）。

---

## 九、验收

30 秒内新用户能回答：

1. 能否预测配对结果？ ✅  
2. 能否看到血统？ ✅  
3. 能否展示专业繁育能力？ ✅  

若第一反应仍是「管理软件」→ 失败。

---

## 开发顺序

| Sprint | 内容 |
|--------|------|
| 1 | 首页重构、模拟入口前置、血统入口前置、底栏调整 |
| 2 | 模拟结果页优化、血统树视觉优化、遗传说明 |
| 3 | 小程序连接模拟结果 / 血统展示 |

---

## 工程约束

- 不改 `geneticcore` 权威规则与推算逻辑
- 不改 CRM / 预订 golden path 核心冻结代码（见 `CORE_CODE_FREEZE.md`）
- Flutter 表现层与导航优先；底层 repository / API 尽量只消费
- 任务 / 财务等能力不删，仅降级入口

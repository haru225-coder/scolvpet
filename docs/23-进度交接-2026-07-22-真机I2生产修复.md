## 3. 根因

### 3.1 生产迁移漂移

- LA1 `scolvpet_meta.schema_migrations` 最后记录为 `0027_genetic_phenotype_feedback.sql`。
- 当前 API 二进制已查询 `hamster.cover_media_id`，但生产表缺少该列。
- 缺失迁移为 `0028–0032`，其中 `0032_hamster_cover_media.sql` 添加 `cover_media_id`、同 owner 外键和部分索引。

### 3.2 静态二进制缺少时区数据库

- 迁移补齐后，内部短期只读 JWT 复现结果：
  - `/v1/hamsters`：200，4 条
  - `/v1/litters`：422，`X-Timezone` 时区格式不正确
  - `/v1/enclosures`：200，0 条
  - `/v1/weight-records`：200，0 条
- `i2RequestLocation()` 对空 header 使用 `Asia/Shanghai`，但 LA1 API 容器没有 `/usr/share/zoneinfo`，静态 Go 二进制也未内嵌 tzdata，因此 `time.LoadLocation("Asia/Shanghai")` 仍失败。
